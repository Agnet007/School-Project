# Glossary

- Principal: user, device, or service identity.
- Permission: atomic allowed action.
- Grant: permission assigned to a principal in a scope.
- Scope: resource context for a grant.
- Entitlement: plan-enabled feature; not authorization.
- Quota: numeric usage limit; not permission.
- LessonDraft: editable lesson working state.
- LessonVersion: immutable published snapshot.
- WorkspaceDocument: versioned user-controlled note, board, thread, sheet, snapshot, or attachment.
- Sync Operation: idempotent local mutation awaiting synchronization.
- Domain Event: immutable fact produced by core behavior.
